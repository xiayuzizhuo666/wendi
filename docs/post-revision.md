## 一句话与团队

- 一句话：把一件好奇的事，问成一份读得完、查得到、能下载的读物。
- 产品形态：网站（React + Vite）+ Qoder Sites Edge Function。
- 团队：问底编辑部（按实际报名信息为准）。

## 它和同场作品的区别

- ResearchBoard / FindAnswer：偏研究流程、资料检索和证据工作台；问底交付的是一份完整可读的成品。
- 第一页：回答“该读什么”；问底回答“这一份可以怎么读、哪些地方还不能确定”。
- SciForge：面向实验数据和论文图表；问底面向任何好奇对象，不要求用户先有实验。
- 普通聊天 AI：给一段对话；问底给一份有结构、有来源分级、有反方、有可信度说明、可保存的读物。

## 工程证据

- 4 个测试文件、14 条断言：来源分级 L1–L6、可信度五信号、Agent zod schema（对象类型/中文置信/立场/rerank/QA）、格式化与字数统计。
- `npm test` 和 `npm run build` 可重复执行；测试不依赖模型 key。
- 线上真实链路：样例阅读、报告生成、来源点击、PDF 下载、演示额度提示均已跑通。
- 关键实现：对象路由；来源清洗、分级、相关性 rerank；引用编号回链；QA 与可信度信号；Typst 浏览器内 PDF；IndexedDB 本地报告库。
